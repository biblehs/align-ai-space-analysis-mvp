# Healing Expression Usage Matrix

## Purpose

ALIGN uses healing language as emotional translation, never as analytical evidence.

This matrix exists to keep the system warm without letting it drift into mysticism, pseudo-medical claims, or vague wellness copy.

## Core rule

- If removing a sentence would not weaken the report's logic, it may be healing expression.
- If removing a sentence would weaken the report's logic, it must stay evidence-led or explanation-led.

## Three layers

### 1. Evidence layer

Role:
- describe what is visible
- stay concrete, specific, and checkable

Good:
- `Bright overhead lighting is still dominating the room at night.`
- `The wall above the dresser is still carrying a large amount of empty visual space.`

Not allowed:
- `The room is holding blocked healing energy.`
- `The wall is carrying a low frequency.`

### 2. Explanation layer

Role:
- explain why the visible signal matters
- preserve product reasoning

Good:
- `Bright overhead light keeps the room feeling more alert than restorative.`
- `Large bare wall space can make the room feel unfinished and harder to settle into.`

Too soft:
- `The room has not opened its healing channel yet.`

### 3. Healing-expression layer

Role:
- translate analysis into felt experience
- add warmth to action framing and CTA transitions

Good:
- `The calm is here, but the deeper settling has not fully arrived yet.`
- `This shift helps the room feel less alert and more able to hold rest.`

Not allowed:
- `This room is healing you already.`
- `Your nervous system is being restored by the room.`

## Snapshot

Use healing expression only in:
- type naming
- one-line reading
- brief state translation
- tonight shift explanation
- CTA transition line

Keep:
- 70-80% clear explanation
- 20-30% healing expression

Good:
- `This room is already quieter, but it is not yet fully supporting rest.`

Not allowed:
- putting healing expression inside proof bullets
- using healing language to explain scores

## Full Report

Use healing expression only in:
- deeper reading opening
- hidden drains translation
- action-plan explanation
- closing reflection

Keep:
- evidence and root-cause sections mostly rational
- healing language as a light support layer

Good:
- `What is missing is not more effort everywhere, but one clearer restorative cue.`

Not allowed:
- replacing zone analysis with poetic summary
- using healing language to justify priority order

## Progress Report

Use healing expression only in:
- progress summary
- what worked reflection
- encouragement / reinforcement line
- next-phase framing

This is the stage where healing expression can be slightly warmer, because the user needs confirmation that their effort mattered.

Good:
- `The room now feels more settled than it did before.`
- `This change is beginning to hold, even if it is not fully stable yet.`

Not allowed:
- `The room is fully healed now.`
- `All resistance has cleared.`

## Review checklist

Before shipping copy, check:

1. Does every proof bullet remain fully evidence-led?
2. Could each healing sentence be removed without weakening the logic?
3. Does any healing phrase introduce a new fact, object, or claim?
4. Does the copy still sound like a space consultant rather than a generic wellness app?
5. Is the action path still clearer than the mood language?
