# ALIGN Knowledge Sources

This file lists the small set of external references used to shape ALIGN's lightweight knowledge system.

The goal is not to create an academic literature dump. The goal is to preserve a few credible anchors so the product stays professional without becoming overbuilt.

## Source principles

- Prefer reviews, institutional research summaries, or official health sources
- Convert knowledge into product rules, not raw theory
- Use these sources mainly for the writer layer and interpretation logic
- Do not let references override visible evidence from the image-analysis layer

## Current lightweight source set

### 1. Light and circadian timing

- PubMed: [Systematic review of light exposure impact on human circadian rhythm](https://pubmed.ncbi.nlm.nih.gov/30311830/)

Used for:

- treating evening or nighttime bright light as a plausible sleep-disrupting cue
- keeping lighting language grounded in circadian timing rather than mystical claims
- favoring lower, softer evening light cues in sleep-oriented guidance

### 2. Restorative environments

- PubMed: [Attention Restoration Theory II: a systematic review](https://pubmed.ncbi.nlm.nih.gov/30130463/)

Used for:

- framing recovery and restoration as supported by environments that reduce directed-attention fatigue
- supporting the concept of restorative cues without over-therapeutic language
- strengthening Align's distinction between calm, clarity, and restoration

### 3. Visual clutter and information load

- National Eye Institute: [Visual clutter alters information flow in the brain](https://www.nei.nih.gov/research-and-training/research-news/visual-clutter-alters-information-flow-brain)

Used for:

- treating visual clutter as a real attentional burden
- supporting product language around visual competition, drag, and cognitive load
- justifying why decluttering or reducing competing cues can matter for focus and perceived ease

### 4. Color and visual environment caution

- Springer: [Limited evidence for the effect of red color on cognitive performance: A meta-analysis](https://link.springer.com/article/10.3758/s13423-020-01772-1)
- Annual Review / Color-in-context theory referenced via summary sources

Used for:

- keeping color claims modest and context-dependent
- avoiding simplistic "blue means calm" or "red means stress" logic
- treating color as one supporting signal among light, contrast, softness, material, and layout

## Product translation rules derived from these sources

1. Light can be a strong state cue, especially for sleep-oriented outputs.
2. Restoration is not the same as neatness; a room can be orderly but still under-restorative.
3. Visual clutter matters because attention competes across stimuli, not because clutter is morally bad.
4. Color should be used as a supporting modifier, not as a deterministic psychological claim.
5. Recommendations should stay low-claim, visible-evidence-based, and practical.
