# Scene Commerce

This module stores structured support-layer content for ALIGN's commerce surfaces.

Principle:

- do not recommend products as decor suggestions
- recommend supports that help the room better support the user's state

Current scope:

- room-specific support copy assets
- kit naming and CTA libraries
- front-end consumable content JSON

This layer should remain downstream of:

1. room analysis
2. tension / contradiction understanding
3. action prioritization

It should never become the basis of diagnosis.
